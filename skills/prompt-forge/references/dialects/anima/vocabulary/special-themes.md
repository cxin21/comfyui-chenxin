## 使用提示

- 跨槽位场景必须先匹配主题配方，再按 §5 决策树对应基础类型填充各槽位。
- NTR 核心在「谁在看/谁知道」——分屏（split screen）+ 电话（talking on phone / smartphone visible）是最强镜头工具。
- 绑标签要写清楚束缚了什么部位（arms/legs/torso/wrists/ankles）；绳痕（`rope marks` + `skindentation`）是真实感关键。
- 物化强调非人化（`objectification` / `degradation` / `used goods`）+ 过量体液（`excessive cum` / `cum bath`）；与普通群交的区别在「被用完后丢弃」的残骸感。
- 男娘与扶她是两个独立体系（`otoko no ko` ≠ `futanari`），不能混用。
- 异种核心在「人类 vs 非人」的体型/力量/数量的绝对不对等——`oviposition` / `egg` 是异种特色结果标签。
- 宠物调教与物化的区别——宠物有「主人-宠物」关系纽带，物化是彻底弃用的肉块。
- 胁迫核心是「权力不对等」而非单纯暴力——把柄威胁（`hidden camera` / `blackmail` / `recording`）是胁迫独有标签。
- 偷窥与展示是同一硬币两面——前者不被发现地看，后者故意给人看。
- 事后分两种方向：温存（`cuddling` / `tender` / `afterglow`）和空虚（`regret` / `ashamed` / `used condom`）。
- 日常表情要 `natural` / `casual` / `expressionless`，不要用任何兴奋/羞耻/高潮标签。
- 大×小必须 `onee-shota` 或明确的 `age difference` + `size difference` 标签。
- 隐奸「隐」的关键在裁剪——`head out of frame` 或 `lower body only` 是最强工具；上半身不能有任何性暗示标签（不要 `blush` / `heavy breathing`）；不要加 `peeping` / `voyeurism` / `hidden camera`（那是偷窥主题）。
