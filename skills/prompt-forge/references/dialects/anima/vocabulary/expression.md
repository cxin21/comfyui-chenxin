## 使用提示

- 同一 prompt 中表情标签不超过 3 个——选最能代表当前强度的。
- 用户未明确描述情绪时，默认取 Lv2。
- Lv3 以上必须搭配至少 1 个身体反应标签。
- 生理反应与高潮反应可叠加（`trembling + arched back + orgasm`），但总数不超过 3 个身体反应。
- 抵抗/顺从二选一；体力消耗按场景强度递增。
- 液体层次选 1-2 级，不跨越超过 2 级（不要同时 `pussy juice` + `bukkake`，除非刻意极端对比）。
- 痕迹隐含前序动作——绳痕暗示束缚、掌印暗示打屁股、书写暗示调教/RBQ。
- 不同角色的液体可叠加（女方 `pussy juice` + 男方 `cum`）。
