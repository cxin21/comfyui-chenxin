# Recipe — Helmut Newton black-and-white

> Pre-composed aesthetic profile for sophisticated / provocative / high-fashion /
> monochrome noir-portrait. Pull when the request mentions "Helmut Newton",
> "fashion noir", "high fashion portrait", "provocative fashion", "黑白时尚".

## 核心公式

> 高端时尚摄影棚里的硬光雕塑——黑白高反差、侧光刻出身体轮廓、长礼服礼服与肌肤光泽。

## 五层组合

- composition: `full body` *or* `medium shot`; `low angle` (empowering subject) *or* `from side` (architectural); `rule of thirds` *or* `negative space`
- lighting: `hard lighting` (Newton's signature) *or* `dramatic lighting`; `side lighting` *or* `rim light`; `studio lighting`; `chiaroscuro`, `partially shadowed`
- palette: `monochrome` (mandatory) *or* `black and white`; `high contrast` (Newton uses pushed blacks); never stack `pastel color` / `vivid color` / `sepia`
- camera: `photo (medium)` (mandatory); `shallow depth of field`, `bokeh`; `35mm` (Newton's signature film look)
- mood-texture: `dramatic` (fashion intensity); clean studio, no weather; `polished` (skin, fabric)

## 氛围链

`半身肖像 (medium shot + side lighting + dramatic) → 全身晚礼服 (full body + low angle + chiaroscuro) → 都市夜景 (negative space + rim light + 35mm) → 雕塑身体 (chiaroscuro + partially shadowed + polished)`

## 使用提示

- 用 Helmut Newton 配方：
  - 高端时尚摄影 / 黑白肖像 / 模特 / 礼服 / 都市夜景 / 雕塑感身体。
  - 用户提到 "Helmut Newton"、"黑白时尚"、"fashion noir"、"高对比摄影" 时。
- 不要用 Helmut Newton 配方：
  - 可爱 / 卡哇伊 / 治愈 / 儿童 / 童话 / 卡通 / 鲜艳色彩。
  - 用户要"可爱"、"柔和"、"彩色"、"插画"——直接冲突。
- 配方强约束：`monochrome` 与 `photo (medium)` 双必备锚点；不要塞 `illustration` / `painting` / `watercolor`。
- 灯光必须 `hard lighting`；`soft lighting` 是 Newton 反面，会破坏硬光雕塑感。
- 高对比度是 Newton 标志：`monochrome` + `high contrast` 必须同时出现。
- 表面质感 `polished`（肌肤 / 礼服面料光泽）；不要 `matte` / `wet` / `worn`。
- 渲染介质严格 `photo (medium)`——Newton 是真实摄影，非插画。
- 镜头签名 `35mm` 是 Newton 关键；如果省略，整体胶片感会减弱。
