# Recipe — film noir

> Pre-composed aesthetic profile for noir detective / crime / urban-night.
> Pull when the request mentions "noir", "detective", "mystery",
> "rain-soaked street", "crime scene", "femme fatale".

## 核心公式

> 都市暗巷里的硬光阴阳脸——侧光雕刻、烟雨反光、黑白高反差、单色胶片颗粒。

## 五层组合 — `general` 槽内

> 以下五层 = `general` 槽位的内部五层（按 general 内部顺序：action/expression → composition → lighting → palette → camera → mood）。action/expression 由场景另行编撰，此处只给后五层的 `general` 标签。

- general·composition: `medium shot` *or* `long shot`; `from side` *or* `low angle`; `leading lines`
- general·lighting: `dramatic lighting`; `side lighting` *or* `partially shadowed`; `neon lights` (urban) *or* `moonlight` (open); `chiaroscuro` for portraits
- general·palette: `monochrome` (default) *or* `noir`; never stack with `pastel color` / `vivid color`
- general·camera: `photo (medium)`; `depth of field`, `bokeh`; `film grain` *or* `35mm`
- general·mood-texture: `mysterious` *or* `dramatic`; `rain` + `reflections` (urban) *or* `fog` (alley); `smoke` (cigarette, vent)

## 氛围链

`城市雨夜 (rain + neon lights + reflections) → 巷道烟雾 (fog + smoke + side lighting) → 肖像阴阳 (chiaroscuro + partially shadowed) → 高反差剪影 (silhouette + backlighting + monochrome)`

## 使用提示

- 用 noir 配方：
  - 侦探 / 犯罪 / 神秘 / 雨夜 / 抽烟 / 烟雾弥漫 / 城市夜色。
  - 用户明确说 "noir"、"黑色电影"、"film noir" 时。
- 不要用 noir 配方：
  - 户外晴天 / 节日庆典 / 儿童场景 / 浪漫爱情 / 童话 / 治愈 / 明亮商业。
  - 用户要"温暖"、"彩色"、"柔和"时——直接冲突。
- 配方强约束：`monochrome` 是默认锚点；不要堆叠 `pastel color` / `vivid color` / `warm color`。
- 灯光默认 `dramatic lighting`；`soft lighting` 在此配方里被禁用。
- 胶片感用 `film grain` 或 `35mm`，二选一即可强化"老电影"质感。
- 雨 + 反光是 noir 城市标签的标配组合；如果场景在干燥室内，用 `fog` 替代 `rain`。
