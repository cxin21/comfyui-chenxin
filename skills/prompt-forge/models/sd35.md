# Stable Diffusion 3.5

SD3.5 是 Stability AI 的旗舰模型，采用 **MMDiT**（Multimodal Diffusion Transformer）架构，使用 **LLM 编码器** 替代传统 CLIP。支持自然语言短句提示词。

## 关联模型

同 LLM 编码器族：[[flux]]、[[anima]]

## 核心规则

### 提示词风格

> [!info] 自然语言短句
> SD3.5 使用**自然语言短句**，而非 Danbooru tag 堆栈。用完整句子描述画面。

### 多语言支持

支持**中英文混合**提示词，中文描述也能被正确理解。

### 负向提示词

负向支持为 **light**（轻度）。只需基本的排除词：
```
low quality, blurry, deformed, bad anatomy, ugly, disfigured, watermark, text, extra limbs
```

### 参数规模

| 版本 | 参数量 |
|------|--------|
| Large | 8B |
| Medium | 2.5B |

## 与 SDXL/SD1.5 的关键差异

| 维度 | SD1.5 / SDXL | SD3.5 |
|------|-------------|-------|
| 编码器 | CLIP | LLM |
| 提示词 | 标签堆栈 | 自然语言 |
| 权重语法 | 括号权重 | 不需要 |
| 中英文混合 | 不支持 | 支持 |
