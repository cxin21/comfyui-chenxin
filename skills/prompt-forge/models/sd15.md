# Stable Diffusion 1.5

Stable Diffusion 1.5 是经典的基础文生图模型。尽管已有更新模型，SD1.5 因其庞大的社区生态（LoRA、Embedding、ControlNet）仍然是很多垂直场景的首选。

## 核心规则

### 标签风格

> [!important] 纯标签 + 括号权重
> SD1.5 使用**纯 Danbooru 标签** + **括号权重语法**。不支持自然语言描述。

### 权重语法

```text
(tag:1.3)   -- 强调权重
[tag:0.8]   -- 减弱权重
```

### Token 限制

Token 限制为 **77**。超过 77 token 时需要用 `BREAK` 关键词分段。每段独立编码后拼接。

### Embedding 负向

> [!warning] 必须使用 embedding
> SD1.5 **必须使用 embedding 负向**。推荐组合：
> - `embedding:easynegative`
> - `embedding:badhandv4`

## 负向提示词（完整版）

```
embedding:easynegative, embedding:badhandv4, worst quality, low quality, normal quality, lowres, watermark, signature, text, jpeg artifacts, blurry, bad anatomy, bad hands, extra fingers, missing fingers, extra limbs, deformed, disfigured, mutation, ugly, poorly drawn face, cloned face
```

## 提示词结构

1. 质量标签
2. 主体描述（Danbooru tags）
3. 场景/环境标签
4. 画师标签
5. 权重格式化 `(tag:weight)`
6. 超过 77 token 时用 `BREAK` 分段
