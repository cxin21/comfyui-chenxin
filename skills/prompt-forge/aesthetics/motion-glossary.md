# Motion-language glossary

Motion wording describes visible change through time. Choose only the dimensions needed to make the requested action unambiguous.

| Dimension | Questions | Example language |
|---|---|---|
| subject | what moves | the swordswoman turns her shoulders |
| path | where it moves | crosses from left to right, arcs downward |
| speed | how quickly | gradually, steadily, snaps into place |
| weight | how mass affects movement | heavy follow-through, buoyant drift |
| amplitude | how far it moves | a slight tremor, one full turn |
| endpoint | how it finishes | stops facing the doorway |
| response | what reacts | sleeves lag behind, rain scatters from the blade |
| persistence | what continues | rainfall remains steady throughout |

## Physical wording examples

- Wind: hair and fabric bend in the same direction; loose ends settle after the gust.
- Water: movement is buoyant and slightly delayed; bubbles rise while cloth trails.
- Impact: contact happens once; fragments move outward and then lose speed.
- Character action: name the body part, path, endpoint, and any prop interaction.
- Camera feel: describe a compatible observation, such as a steady lateral follow or a slow approach.

Motion language cannot add an action, object, injury, or environmental event that is absent from evidence. When timing or causality is uncertain, preserve it as uncertainty.
